# PROMPT MANIA — Framework Engineering Library

A luxury-grade, high-precision prompt engineering library and AI architect workspace. Designed for prompt engineers, AI architects, researchers, and developers to craft, test, and master structured prompting paradigms.

---

## ⚡ Features

- **8 Core Prompting Frameworks**:
  - **RACE**: Role · Action · Context · Explanation
  - **CO-STAR**: Context · Objective · Style · Tone · Audience · Response
  - **RTF**: Role · Task · Format
  - **APE**: Action · Purpose · Expectation
  - **TAG**: Task · Action · Goal
  - **RISEN**: Role · Instructions · Steps · End Goal · Narrowing
  - **CREATE**: Character · Request · Examples · Adjustments · Type · Extras
  - **ROLE**: Role · Objective · Layout · Evaluation

- **Dynamic Bento Grid**:
  - Contextual 3, 4, 5, and 6-module layout architecture.
  - Distinct visual separation between Official Core Modules and Recommended Additions.

- **AI Framework Architect**:
  - Generate domain-tailored, multi-step prompt frameworks using prompt heuristics and domain analysis.
  - Interactive inspection and JSON export.

- **Custom Framework Studio**:
  - Create and edit bespoke prompting frameworks with persistent `localStorage` support.
  - Favorite and pin frequently used frameworks.

- **Ready-to-Run Assembled Prompts**:
  - Copy assembled prompts formatted in structured Markdown with one click.
  - Instant direct launch links to ChatGPT and Claude.

- **Custom Luxury Design System**:
  - Signature British Racing Green accent theme with milled glassmorphism.
  - Responsive micro-animations and dynamic robot avatar generator.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18.0.0 or higher recommended)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```

### Linting
```bash
npm run lint
```
